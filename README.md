# Ledger — サブスクと買い物の記録（iPhone用Webアプリ）

自分のiPhoneだけで使う、出費・サブスク管理アプリです。
ビルド不要のWebアプリ（PWA）なので、Windows + VSCode だけで開発・更新できます。
**記録したデータはiPhoneの中（Safariのストレージ）にだけ保存され、外部には送信されません。**
ネットに出るのはドル→円の為替レートの取得だけです。

## ファイル構成

```
ledger/
├─ index.html            画面の骨組み
├─ styles.css            見た目（ダークテーマ）
├─ app.js                機能すべて（データ処理・グラフ・カレンダーなど）
├─ manifest.webmanifest  ホーム画面に追加したときのアプリ名・アイコン
├─ sw.js                 オフライン起動用（Service Worker）
└─ icons/                アプリアイコン
```

## 1. Windowsで動作確認する

1. VSCodeでこのフォルダを開く
2. 拡張機能「Live Server」を入れ、`index.html` を右クリック →「Open with Live Server」
3. Chromeで開いたら `F12` →「デバイスツールバー」（スマホのアイコン）→ iPhone サイズを選ぶ

同じWi-FiのiPhoneから `http://<PCのIPアドレス>:5500` を開いても確認できます（この方法だとオフライン機能だけは動きません）。

## 2. iPhoneに入れる（GitHub Pagesで公開・無料）

ホーム画面アプリとしてオフラインでも使うには、HTTPSのURLが必要です。GitHub Pagesを使うのが一番簡単です。

1. GitHubでアカウントを作り、新しいリポジトリを作る（例：`ledger`、Public）
2. 「Add file」→「Upload files」で、このフォルダの中身をすべてドラッグ＆ドロップして「Commit changes」
3. リポジトリの「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして Save
4. 1〜2分待つと `https://<ユーザー名>.github.io/ledger/` で開けるようになる
5. iPhoneの **Safari** でそのURLを開く →「共有」→「ホーム画面に追加」（「Webアプリとして開く」はオン）

> 公開されるのはアプリのプログラムだけです。入力したデータはiPhoneの中にしかないので、他人がURLを開いても見えません。
> GitHubを使いたくない場合は、Netlify Drop（https://app.netlify.com/drop）にフォルダをドラッグするだけでも公開できます。

## 3. アプリを更新する

1. VSCodeでファイルを編集
2. `sw.js` の `VERSION`（例：`ledger-v1` → `ledger-v2`）を書き換える
3. GitHubに同じ手順でアップロード（上書き）
4. iPhoneでアプリを一度閉じて開き直すと新しい版になる

データは更新しても消えません。

## 4. 使い方

| 画面 | できること |
|---|---|
| 出費 | 月ごとの合計。「合計 ↔ サブスク ↔ 買い物」は横スワイプかタブで切り替え。半円グラフはそれぞれ「ジャンル別」「サービス別」「支払い方法別」の割合 |
| ＋ボタン | 項目を追加。毎月・毎年を選ぶと翌月以降の支払いが自動で入る。一回のみの場合は分割回数（2〜60回）を選べる |
| カレンダー | 引き落とし予定日をTimeTree風に表示。帯の色はカード（支払い方法）の色。左右スワイプで月移動、日付をタップでその日の明細 |
| 履歴 | 今日までのすべての支払い。検索・ジャンル絞り込み・月ごとの小計 |
| 設定 | カードの登録（名前・下4桁・色）、為替レート、バックアップ |

- 項目をタップすると詳細が開き、編集・削除・「今日で解約」ができます（解約すると以降の支払いが出なくなり、過去の記録は残ります）
- ドル建ての項目は、自動取得したレート（6時間ごと更新）で円に換算して合計します。設定から手動で固定もできます
- 月の表示（「2026 11月」）をタップすると今月に戻ります

## 5. データの保存について（大事）

- データはiPhoneのSafari内（このアプリ専用の領域）に保存されます
- **ホーム画面のアイコンを削除するとデータも消えます**
- 機種変更の前や、月に一度くらいは「設定 → バックアップを書き出す」で「ファイル」アプリに保存してください。新しいiPhoneでは「バックアップから復元」で戻せます

## 6. できないこと

- **ホーム画面ウィジェット**：iPhoneのウィジェットはネイティブアプリでしか作れないため、この方式では作れません
- 通知（引き落とし前のリマインドなど）は未対応です
